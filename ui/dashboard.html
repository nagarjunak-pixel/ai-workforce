Agent → Harness → Loops → Memory

The AI Workforce is built on four layers. Each layer makes the system more reliable and intelligent.

🧠 Agent

Wraps an LLM with a role-specific system prompt. Each agent is an "employee" — CEO, Researcher, Coder, QA, Docs, Deploy, Marketing. Each gets the right model for their job (coder model for coding, heavy model for planning).

🛡️ Harness

Safety layer: retry with exponential backoff, circuit breaker (3 failures → open → 30s cooldown → half-open), timeout enforcement, response validation. Makes the workforce reliable instead of fragile.

🔄 Loops

Self-improvement: generate → score → check convergence → adapt → repeat. Each cycle, the agent tries to improve its output. The scorer evaluates length, code presence, examples, and structure. Meta-learner adjusts temperature if stuck.

💾 Memory

SQLite-backed persistence: every interaction recorded, project state saved, per-agent knowledge stored. Agents remember what worked, what didn't, and the current project context.

Tech Stack

  • • LLMs: Ollama local models (qwen3.5:4b, qwen2.5-coder:7b, qwen3.5:35b-a3b)
  • • Framework: FastAPI + httpx (async)
  • • Database: SQLite (built into Python — zero infrastructure)
  • • UI: Tailwind CDN dark theme dashboard
  • • Pattern: Agent → Harness → Loops → Memory
